# CodeAlpha Internship — Task 1: Web Scraping

## What This Does
Scrapes **quotes, authors, and tags** from `quotes.toscrape.com` (a legal practice website), saves everything to a CSV file, and shows basic analysis.

## Libraries Required
Install with:
```bash
pip install requests beautifulsoup4 pandas
```

## How to Run
```bash
python task1_web_scraping.py
```

## Output
- `scraped_quotes.csv` — all scraped data
- Console shows: total quotes, top authors, top tags
